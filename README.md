# Projet Fédéré - Gestion scolaire

Application de gestion scolaire développée en Java (JavaFX) avec MySQL.

## Fonctionnalités

- Gestion des élèves, enseignants, classes et matières
- Inscriptions et affectations
- Saisie des notes et génération des bulletins
- Authentification (connexion / inscription)

## Technologies

- Java, JavaFX
- Maven
- MySQL

## Installation

1. Cloner le dépôt : `git clone https://github.com/yahiachakchouk5-sudo/projet-federe.git`
2. Importer la base de données avec `school_management_mysql.sql`
3. Configurer la connexion dans `DatabaseConnection.java`
4. Lancer l'application avec Maven : `mvn javafx:run`
